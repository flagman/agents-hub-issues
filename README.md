# Agents Hub — issues

Ошибки и пожелания к приложению Agents Hub. Кода здесь нет — только issues.

Обычно issue заводит Hub Developer внутри вашего хаба: он описывает, что случилось, версию хаба и шаги, чтобы
повторить. Можно завести и вручную: **New issue**.

Не прикладывайте журнал хаба, токены и личные данные — issues видны всем.
